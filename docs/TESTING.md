# Проверка CustomWeapons

## Автоматические проверки

`dotnet test -c Release` проверяет матрицу server/sid/expires, привязку игрока и скина, дубликаты, ограничения каталога, отказ и восстановление состояния доступа, нормализацию оружия, краткий снимок гранат, сохранение/сброс/повреждение JSON и ошибку соединения MySQL.

Интеграционный тест использует `CW_TEST_MYSQL` и **создаёт тестовые таблицы и тестового пользователя**. Запускайте его только в новом одноразовом MySQL 8.x. Имя БД обязано начинаться с `cw_test_`; тест требует административного подключения для подготовки. Производственный код использует только SELECT. CI поднимает MySQL 8.4, создаёт схему пользователя без изменений и проверяет чтение из аккаунта с правами SELECT.

Без переменной интеграционный тест помечается skipped. Не передавайте этому тесту адрес или учётные данные рабочей БД.

## Проверка в игре — пока не выполнена

Нужны тестовый сервер CS2 с CounterStrikeSharp 1.0.375+, контент всех шести моделей и два игрока. Автотесты не загружают нативный движок и не подтверждают работу SetModel или качество анимаций.

1. Запустить плагин, сменить карту, проверить отсутствие ошибок precache.
2. Проверить `!cw`, `!customweapons`, консольные команды, переход назад, страницы и выход.
3. Выдать действующие доступы средствами существующей панели. Проверить каждый из шести скинов: модель от первого и третьего лица, стрельбу, перезарядку, осмотр и модель на земле.
4. Выбрать скин до покупки/появления. Купить/получить оружие, проверить автоматическое применение. Проверить M4A1 и M4A1-S как разные категории.
5. Передать оформленное оружие второму игроку без доступа. Модель остаётся; его сохранённый выбор не заменяет её автоматически. Ручной сброс возвращает исходную модель.
6. Истечь/отозвать доступ, дождаться опроса. Существующий экземпляр сохраняет модель; новый её не получает. Проверить также `active=0`.
7. Проверить `sid=0`, точный `sid`, чужой `sid` и `ServerId=0`; бессрочный и истёкший доступы.
8. Проверить private/public и Hide true/false, отсутствие строки cw_skins, конфликтующие дубликаты.
9. Проверить cooldown и сброс, выбор будучи мёртвым, несколько экземпляров одного типа.
10. Переподключиться, перезапустить сервер, проверить сохранение; повторить с `SaveSelections=false`.
11. Отключить MySQL, дождаться ошибки опроса: новые приватные применения запрещены, существующие модели сохранены. Восстановить БД — доступы возвращаются после опроса.
12. Добавить совместимый нож, проверить применение без смены игрового типа. Добавить совместимые гранаты, проверить руки и снаряды, броски подряд, передачу гранаты и смерть при удержании.
13. Выгрузить плагин: модели восстанавливаются, меню других плагинов остаются. Горячо загрузить: новые установки блокируются до смены карты.
14. Сменить карту и повторно подключиться во время запроса БД: старый результат не должен примениться к новому игроку в том же слоте.

Результаты этой ручной проверки должны быть зафиксированы администратором сервера перед использованием на рабочем сервере.
